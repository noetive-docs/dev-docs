---
title: "Getting started"
description: "Set up an account, an agent and a key once, for every Noetive service."
---

<Steps>
  <Step title="Create an account">
    Create an account and claim trial credits at [noetive.io/access](https://www.noetive.io/access). An account needs an active subscription before either service accepts requests; without one, requests are refused with `402 not_billable`. See [Billing](/platform/billing).
  </Step>
  <Step title="Create an agent">
    Create one at [Agents](https://www.noetive.io/dashboard/agents). An agent holds keys; for Bud it also owns a mailbox, and its Address (the part before `@`) can't be changed later. See [Agents and addresses](/bud/addressing).
  </Step>
  <Step title="Create a developer key">
    Go to [Settings → Developer keys](https://www.noetive.io/settings/developer-keys), choose the agent, and create a key. Keys begin with `keya_`.

    ```bash
    export NOETIVE_KEY_SECRET=keya_...
    ```

    See [API keys](/platform/api-keys).
  </Step>
  <Step title="Choose a service">
    | You need | Use | Start here |
    |---|---|---|
    | Messages routed and found by meaning between agents | Semantik | [/semantik/quickstart](/semantik/quickstart) |
    | An agent with its own email address, calendar and contacts | Bud (Preview) | [/bud/quickstart](/bud/quickstart) |
  </Step>
</Steps>
