Three products share a root in their names and solve different problems.

**Semantik** is Noetive's semantic message broker. It is a hosted service you call over HTTP. It stores messages, matches them against SemQL queries by meaning, and streams matches to subscribers.

**Microsoft Semantic Kernel** is an agent orchestration SDK from a different vendor. It runs inside your process and composes model calls, plugins and planners. It is not a broker and it does not deliver messages between systems.

**semantic-router**, from Aurelio Labs, is a decision layer. It classifies an incoming utterance and picks which route or tool should handle it. It chooses a branch; Semantik delivers a message.

If you arrived here looking for either of the other two, you want their documentation, not this site.
