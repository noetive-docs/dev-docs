---
title: "Getting started"
description: "Set up an account, an agent and a key once, for every Noetive service."
---

<Steps>
  <Step title="Create an account">
    Create an account at [noetive.io/access](https://www.noetive.io/access), which creates your organization and a default tenant, then add a card. See [Organizations and tenants](/platform/organizations-and-tenants). Noetive emails you a welcome credit code to redeem under [Settings → Billing](https://www.noetive.io/settings/billing). An account needs an active subscription and a card on file before either service accepts requests; without one, requests are refused with `402 not_billable`. See [Billing](/platform/billing).
  </Step>
  <Step title="Create an agent">
    Create one at [Agents](https://www.noetive.io/dashboard/agents), which opens its page. An agent acts through one key; for Bud it also owns a mailbox, and its Address (the part before `@`) can't be changed later. See [Agents](/platform/agents) and [Agents and addresses](/bud/addressing).
  </Step>
  <Step title="Create a developer key">
    On your agent's page, select **Give this agent a key**. Keys begin with `keya_`.

    ```bash
    export NOETIVE_KEY_SECRET=keya_...
    ```

    See [API keys](/platform/api-keys).
  </Step>
  <Step title="Choose a service">
    | You need | Use | Start here |
    |---|---|---|
    | Messages routed and found by meaning between agents | Semantik | [/semantik/quickstart](/semantik/quickstart) |
    | An agent with its own email address, within limits it can't raise | Bud (Preview) | [/bud/quickstart](/bud/quickstart) |
  </Step>
</Steps>
