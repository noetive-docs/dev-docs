---
title: "Namespaces"
description: "Isolated message scopes within your Noetive account."
---

A namespace is an independent scope for messages and subscriptions in Semantik. Messages published to one namespace are not visible to subscribers in another. Each namespace has its own real-time metrics.

## What identifies a namespace

A namespace is identified by three values together: its **name**, its **embedding model**, and its **dimension count**. All three are required on every publish, search and subscribe, and Semantik guesses none of them.

The reason is that one name can carry more than one embedding configuration, and vectors produced by different models are not comparable. If the model were inferred, a query could be answered in the wrong space and return confidently wrong results.

<Warning>
  The wire `namespace` field and the SemQL `NAMESPACE` clause both take the namespace **name**. The internal `ns_...` identifier shown in the dashboard is rejected with an error telling you to use an alias.
</Warning>

## Creating a namespace

1. Go to the [Semantik dashboard](https://noetive.io/dashboard/semantik).
2. In the namespace table, select **New namespace**.
3. Enter a name and save.

Names are case-insensitive.

<Info>
  Namespace creation requires an active subscription. If you land on a subscription-required page, complete billing setup under [Settings → Billing](https://noetive.io/settings/billing) first.
</Info>

## The shared global namespace

`global` is a well-known namespace available to every account, provisioned for the `Qwen3-Embedding-4B` model at 1024 dimensions. Other model and dimension combinations under that name are not provisioned and are refused.

<Warning>
  `global` is shared across customers. Messages you publish there are readable by other Noetive accounts. Use a namespace of your own for anything you would not want a stranger to search.
</Warning>

## Targeting a namespace

Name a namespace in SemQL via the `NAMESPACE` clause:

```sql
MATCH DISTANCE("payment failure") WITHIN 0.5
NAMESPACE "acme-prod"
LIMIT 20
```

You can target more than one:

```sql
MATCH DIRECTION(["outage", "service degradation"]) CONE 0.4
NAMESPACE "acme-prod", "acme-staging"
```

See [SemQL query language](/semantik/query-language) for the full namespace selector syntax.

## Editing a namespace

Select **Edit** next to a namespace in the table to update its name.

## Deleting a namespace

<Warning>
  Deleting a namespace is irreversible. All messages, subscriptions, and metrics for that namespace are permanently removed. Active subscriptions in the namespace are terminated immediately.
</Warning>

Select **Delete** next to a namespace in the table and confirm the action.
